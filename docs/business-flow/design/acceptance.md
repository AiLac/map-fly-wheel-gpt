# 验收方法与记录

本轮实际结果见 [2026-09-11 验证记录](validation-2026-09-11.md)。

本文件定义 v1 需要观察的行为。勾选项必须附实际命令、环境、结果或源文件证据；测试数量本身不是覆盖率。真实 Windows 公司宿主与真实 RPC 框架尚需接入验收，不能由 Linux 上的合成夹具替代。

## 确定性工具验收

| 范围 | 输入与观察点 | 通过条件 |
| --- | --- | --- |
| 构建 | JDK 21 / Maven `verify` | 编译成功，行为测试通过，可运行 JAR |
| 选择器 | class、单/多/重复 url、class+url、all、resume、无参数 | 归一一致；互斥冲突报可操作错误；无参数不全量 |
| 源码事实 | 非 Controller 类、显式 imports、条件/早返回/异常 | 源位置可复查；不假设命名 stereotype；诊断未支持机制 |
| 模块隔离 | 两模块相同符号、不同依赖版本 | 不共用 union classpath 产生错误声明解析 |
| RPC 特例 | wrapper implements 同接口、服务端不 implements | 接收字段按实际规则匹配，不伪造本地递归 |
| RPC 身份 | 缺 operation 证据、同 schema 不同服务、响应适配未知 | 保持候选；服务/schema/operation 不混淆 |
| 人工修订 | 新增、换目标、禁用、重复补丁、旧指纹 | 可补漏；冲突拒绝；重扫保留人工文件 |
| 条件目标 | 多候选与已知条件多目标 | 候选不进确认边；条件引用和路由证据有效 |
| 调度 | 依赖未完成、总/阶段并发、重试和超时 | 领取和完成遵守契约，子任务不绕过额度 |
| 恢复 | 同快照恢复、源码/规则变化、异常中断 | 输入保留；变化失效化；旧完成状态不混用 |
| 记忆 | 新增、读取、验证、更正、冲突更新、删除 | 时间语义分离；revision/CAS 生效；墓碑/历史保留 |
| 新鲜度 | 源变化、源缺失、切换版本 | stale/unavailable 区分，不自动假设记忆事实已被推翻 |
| 发布 | 缺失证据、过时指纹、partial 图、完整图 | 引用可追溯；缺口不完整发布；临时证据先持久化 |

## Skill 独立演练

评估者仅收到 Skill、用户输入及最小原始代码和配置，不能收到作者期待答案。演练产物写隔离运行目录，不能写入真实 canonical 文件。

建议任务包含以下独立挑战：给出脱敏 RPC 示例但没有真实 imports/版本；同 URL 在不同服务重复；类位于 Service 层；一个普通条件分支与一个无法解析的远端目标共存；记忆与当前代码冲突；分析中断后恢复。记录实际动作、停止点、问题、引用、任务状态和遗漏。独立复核通过也不能证明公司框架已验证。

## Windows 与公司 Agent 接入

在目标 PC 上确认 Java 21、Maven、UTF-8、带空格中文路径、模块 classpath 与依赖获取。启动公司 Agent 后确认 `.cac` 的 6 个 Skill、command 参数替换、3 个 subagent 的发现与调用；派发量符合配置，子代理仅写任务目录。测试一次真实小入口、RPC 学习、人工修订及中断恢复。

## 结果记录格式

每轮在 `design/` 下保存独立结果文件，写明 UTC 时间、仓库提交或源指纹、平台与工具版本、实际命令、观察结果、失败修正和仍未验证项。正式交付记录由负责运行测试的实现者填写，不预先将上述目标标为通过。
