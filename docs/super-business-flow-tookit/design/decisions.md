# 设计决策与备选方案

本记录说明当前取舍及重新评估条件；不把后续平台设计提前塞进个人 PC 版本。

| 决策 | 当前方案与理由 | 备选及代价 | 何时重评 |
| --- | --- | --- | --- |
| 仓库组织 | 多个独立 Git checkout + 显式 repo/module/service 身份，符合现有代码管理 | 合并 monorepo 可统一依赖/提交，但需迁移团队流程，超出本任务 | 团队正式决定变更仓库治理 |
| 工具与数据目录 | `docs/super-business-flow-tookit/` 存发行内容，`docs/super-business-flow/` 存项目配置与产物；升级边界清晰，名称对应 Skill 前缀 | 单根分子目录迁移成本低，但升级容易覆盖工程数据；独立工具安装路径可复用多工作区，但增加路径解析和版本配对成本 | 多工作区统一管理工具版本成为实际需求 |
| 目录迁移 | 分类搬移、重查活动引用和指纹、新运行验证；保留不可变历史；未完成 run 先用旧版完成或归档 | 全局替换最快，但会改写审计证据、破坏指纹；跨版本自动迁移需要额外状态兼容协议 | 有真实重复迁移成本，并能定义可验证的转换规则 |
| 总体分工 | Skill 做语义，Java CLI 做事实/校验，配置做可修订契约 | 纯 prompt 成本低但结果难复查；完整编译器/平台建设成本高 | 有真实误判或吞吐瓶颈支持扩展 |
| 命令命名 | `/super-business-flow-start` 表示用户启动或恢复流程的入口，主 Skill `super-business-flow` 保持能力名称；命令引用 Skill，不复制分析规范 | 同名更短但容易混淆入口与能力；`-analyze` 强调分析动作，`-start` 更符合统一入口的定位 | 出现有独立用户目标的新命令时 |
| 分析底座 | JavaParser + Symbol Solver，JDK 21，可按模块解析 | 文本搜索快但类型/调用点不可靠；Soot/WALA 等需要更多字节码与运行假设；LSP 依赖宿主状态 | 真实框架需要 CFG/字节码事实时 |
| classpath | 每模块独立依赖，源根显式配置 | 合并依赖简单但同名类与版本冲突会产生错误解析 | 只能做性能优化，不能放弃隔离 |
| RPC 学习 | 程序员示例 + Agent 查实现 + 独立验证，frameworks 可单独运行 | 手写完整规范准确但维护负担高；自动猜测框架不可信 | 真实机制稳定后提供专用适配器 |
| 规则表达 | 有限 DSL 拒绝未实现操作，协议与执行能力分开 | 任意脚本插件表达力强，但执行和版本治理更复杂 | DSL 无法表达真实必需机制时 |
| 映射治理 | generated / overrides / effective 三层，带证据与前置指纹 | 直接编辑生成文件更短，但重扫易丢知识且无法解释冲突 | 保持分层，后续可加界面 |
| 入口选择 | 类、URL 的交集和显式全量，保留歧义 | 默认选唯一近似候选省事，但可能分析错场景 | 不放松真实性约束 |
| 并发 | 可配置全局 + 阶段上限，有限任务包，主代理合并 | 每 repo 一个 Agent 易失去跨服务上下文；递归派发易超预算 | 用真实任务统计调整限额 |
| 记忆 | Markdown 条目 + 元数据索引，CAS/版本/证据与墓碑 | 向量库语义检索强但多一个服务；只存聊天摘要难以查证 | 记忆规模或查询质量证明确需索引升级 |
| 恢复 | 冻结快照 + frontier；变化时保守失效化 | 精细依赖失效可节约成本，但初期易漏掉影响范围 | 性能数据证明保守重跑过贵 |
| 发布 | Markdown/Mermaid + 机器图 + 持久证据，区分 partial/complete | 仅图文方便人读但无法支持 badcase；图数据库便于查询但运维重 | 跨团队复用和动态图查询成型 |
| 宿主集成 | `.cac` Skill/command/agent，CLI 通过独立 argv 执行 | 专用 MCP/服务可增加工具体验但部署复杂 | 首个公司宿主试用后明确必要接口 |

## 核心不变量

没有证据的机制和目标不能成为已确认边；未解决缺口不能标为完整；正常条件分支不能被误判成需要运行值才能分析。人工覆盖保留，但不掩盖矛盾源事实。记忆永远不替代规则和映射的权威文件。临时运行目录不成为长期知识唯一依据。

## 验证层次

Schema 检查格式；工具测试检查可复现的映射、快照、CAS 等行为；Skill 独立演练检查面对歧义时是否遵守停止规则；程序员用真实框架与业务样本完成领域验收。这些层次互相补充，不能用其中一项代替全部。
